# ProxyPilot 1.5.34 发布说明（移除附件管理页、显示 CDN 域名）

日期：2026-11-22
版本：面板 V1.5.34 / Agent 1.4.2 / VPN 客户端 1.4.1

## 变更

1. 删除后台「附件管理」页面：
   - 侧边栏菜单、路由、页面组件均移除；
   - 不再提供独立的上传/下载/删除/重命名页面；
   - 模板与域名列表需要的附件编辑能力保留在订阅模板页。
2. 对象存储设置迁移：
   - 「对象存储设置」按钮移到订阅模板页顶部；
   - Bucket、Endpoint、CDN 公共地址、Account ID、Access Key 仍在同一弹窗配置。
3. CDN 域名展示：
   - 订阅模板页顶部显示 CDN 域名（`cdn_base_url`），支持复制；
   - 模板表格在存储桶 key 下显示完整 CDN URL，支持打开/复制；
   - 域名列表卡片继续显示每个 `.list` 的 CDN URL；
   - 模板编辑页顶部显示模板完整 CDN URL；
   - 未配置 CDN 时有提示。
4. 只保留模板和域名列表编辑：
   - 模板表 + 内容编辑；
   - `rule/*.list` 域名列表管理与编辑；
   - 模板/列表内容继续直接读写存储桶。

## 验证

- 面板 healthz V1.5.34，15/15 节点在线；
- 存储状态接口返回：
  - Bucket `proxypilot`；
  - CDN `https://s3.proxypilot.yangzifun.org`；
- 模板 API 返回 bucket_key 与完整 CDN URL；
- web-antd 构建成功，附件管理菜单/路由不存在；
- jsdom：模板页显示 CDN 域名、模板完整 URL、域名列表；模板/列表编辑可用；
- DoH 外部请求仍正常；
- server 测试全绿；
- 全量发布 dist-release 更新 V1.5.34。

## 注意

- 文件上传/下载/删除/重命名入口已随附件管理页移除，后续文件维护需通过对象存储控制台；
- 模板与域名列表仍可在面板直接编辑并立即生效；
- 对象存储设置需要 R2 配置和写权限。
