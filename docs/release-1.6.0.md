# ProxyPilot 1.6.0 发布说明（全后台主题统一）

日期：2026-11-22
版本：面板 V1.6.0 / Agent 1.4.2 / VPN 客户端 1.4.1

## 一、主题体系重构

- 新增语义 CSS 变量体系：背景、卡片、文字、边框、主色、状态色、表格、输入、代码区、阴影、圆角、图表色板等；
- 新增 `theme/tokens.js`：
  - 5 套站点主题：默认、翠绿、极简、扁平、毛玻璃；
  - 6 套服务端卡片主题：深色、翠绿、极简、扁平、毛玻璃、霓虹；
  - `buildAntdTheme()` 生成完整 Ant Design token 与组件配置。
- 新增 `ThemeProvider` / `useAppTheme`：
  - 全局唯一 ConfigProvider；
  - 主题切换实时生效；
  - 保留原 `theme.js` 导出兼容；
  - 首屏写入主题变量，避免闪烁。
- `PageCard`、`StatCard`、`Toolbar` 改用语义变量，并新增 `DataCard`、`FormCard`、`SectionCard`。

## 二、页面与组件迁移

已完成全后台页面与主要组件的主题变量替换：

- 页面：
  - 系统概览、监控、用户流量、安全中心、证书、日志；
  - 订阅用户、用户详情、节点服务、服务器、节点配置、节点绑定、本机管理；
  - 订阅模板、模板编辑器、mihomo、sing-box 编辑器、系统设置、管理账号、备份、WARP、MTProto、域名优先。
- 组件：
  - 表单、表格、卡片、标签、按钮、弹窗、抽屉、消息；
  - CDN 域名字段、邮箱绑定、任务中心、邮件向导、通知设置、对象存储设置；
  - 服务端卡片、Drawer、Unlock Modal。
- 图表与特殊页面：
  - SVG 折线/柱状/环形/Sparkline/Gauge 使用主题色板；
  - FlowGraph、Globe3D、GlobeMap 随主题切换；
  - 登录页、登录动画主题化；
  - RemoteShell 终端使用代码区语义变量，并随主题切换刷新 xterm 主题；
  - YAML/JSON/版本代码块使用统一 code token。
- 外壳：
  - 侧边栏/顶栏/头像/导航 accent/空态/状态色统一变量；
  - `nav.jsx` 页面 accent 改为主题变量；
  - `format.js` 指标颜色改为语义变量。
- 服务端 6 套主题改为局部变量映射，不再全局污染；Drawer/Modal/Table 等在其作用域内跟随主题。

## 注意

- 当前 5 套站点主题均为浅色体系，未新增全站深色模式；深色仅用于服务端卡片主题；
- 部分图表/光晕使用 `color-mix`，需要较新浏览器；旧浏览器仅影响 tint，不影响功能；
- 服务端主题只在节点页容器内生效；
- 代码编辑区颜色由 `--pp-code-bg/--pp-code-text` 控制，主题切换下保持可读性。
