# ProxyPilot 1.5.28 发布说明（模板编辑页操作调整）

日期：2026-11-22
版本：面板 V1.5.28 / Agent 1.4.2 / VPN 客户端 1.4.1

## 变更

- 模板编辑页按“编辑即写存储桶”调整：
  - 移除顶部「发布」主按钮和发布确认弹窗；
  - 「保存到存储桶」改为顶部主按钮，保存即写 bucket 并立即生效；
  - 状态标签简化为「已保存到存储桶」/「已修改（未保存）」；
  - 版本历史保留，回滚后提示点击「保存到存储桶」重新生效；
  - 预览说明、关闭确认等文案同步改为“保存到存储桶”，不再提示必须发布；
  - 模板地址显示为存储桶 key，不再显示 CDN URL。
- 后端发布接口仍保留兼容，但页面不再暴露发布操作。

## 验证

- web-antd 构建成功；
- 模板编辑器保存仍调用 `PUT /api/templates/manage/{id}/content`，由后端直写存储桶并返回 `source:"bucket"`；
- 顶部只保留校验/预览/保存到存储桶/版本历史/重新加载/关闭；
- server 测试全绿；
- 面板 healthz V1.5.28，15/15 节点在线；
- 全量发布 dist-release 更新 V1.5.28。

## 注意

- 保存需要 R2 已配置且有写权限；
- 版本历史回滚只恢复内容，需要再点「保存到存储桶」才会写入并影响订阅；
- 如果还需要调整字段布局（例如基础设置宽屏/紧凑模式），可继续说明具体期望。
