# ProxyPilot 1.5.30 发布说明（模板编辑页多卡片布局）

日期：2026-11-22
版本：面板 V1.5.30 / Agent 1.4.2 / VPN 客户端 1.4.1

## 变更

- 模板编辑页基础设置按语义拆成多个卡片：
  - 网络与端口；
  - 运行与日志；
  - 连接与保活；
  - 其它（未匹配字段兜底）；
- DNS / TUN 使用各自卡片；
- 卡片间 12px 间距，无字段的卡片自动隐藏；
- 卡片内部保持：
  - 短字段两列；
  - 开关紧凑行；
  - 长文本/JSON 独占整行；
  - 轻量删除操作；
- 保留「应用到编辑内容」和未应用提示；
- 顶部两行 sticky 操作栏、左侧分组导航、移动端底部保存保持不变。

## 验证

- web-antd 构建成功；
- jsdom：基础设置渲染 4 个卡片，字段归属正确；DNS/TUN 单卡片；两列、开关紧凑、长字段整行；无 JS 错误；
- server 测试全绿；
- 面板 healthz V1.5.30，15/15 节点在线；
- 全量发布 dist-release 更新 V1.5.30。

## 注意

- 本次仅编辑页布局调整，不改变模板保存/存储桶直存逻辑；
- 卡片分组按字段名语义匹配，未匹配字段归入「其它」。
