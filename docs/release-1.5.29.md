# ProxyPilot 1.5.29 发布说明（模板编辑页布局重构）

日期：2026-11-22
版本：面板 V1.5.29 / Agent 1.4.2 / VPN 客户端 1.4.1

## 变更

1. 顶部操作栏改为 sticky 两行：
   - 信息行：模板名、保存状态、存储桶 key + 复制、摘要、上次保存时间；
   - 操作行：校验、预览、版本历史、重新加载 +「保存到存储桶」primary 靠右；
   - 关闭按钮独立最右，与保存按钮保持距离；
   - 发布按钮保持移除。
2. 左侧导航：
   - 宽度 232px，按「基础 / 策略与规则 / 原始内容」分组；
   - 保留各分区数量；
   - <1200px 收窄到 180px，<768px 隐藏并改为顶部下拉/移动端底部保存。
3. 表单布局：
   - 基础设置/DNS/TUN 使用 ObjectForm 响应式两列；
   - 短字段两列、长文本/JSON 独占整行；
   - 开关字段改为紧凑行，不再拉伸整行；
   - 行删除操作改为轻量图标，不再大面积红色。
4. 保存与状态：
   - 全局「保存到存储桶」为唯一主操作；
   - 分区按钮改为「应用到编辑内容」，明确只改本地内容，不写 bucket；
   - 状态统一「已保存到存储桶 / 已修改未保存 / 保存失败」；
   - 保留 Ctrl/Cmd+S 提示与关闭前未保存确认。
5. 响应式：
   - 1440 宽无横向滚动，主保存按钮始终可见；
   - 移动端保存按钮固定底部。

## 验证

- web-antd 构建成功；
- jsdom 验证：
  - 顶部信息/操作两行、保存 primary、关闭独立；
  - ObjectForm 两列、开关紧凑、长字段整行；
  - 导航分组/计数/折叠；
  - 状态切到「已修改未保存」；
  - 无 JS 错误；
- server 测试全绿；
- 面板 healthz V1.5.29，15/15 节点在线；
- 全量发布 dist-release 更新 V1.5.29。

## 注意

- 本次仅布局/交互调整，不改变模板 bucket 直存与用户订阅读取逻辑；
- 真实浏览器目视效果需登录后台确认；如某个分区仍显得过宽或过密，可继续按分区微调。
