# ProxyPilot 1.5.10 发布说明（节点绑定模板列合并）

日期：2026-11-21
版本：面板 V1.5.10 / Agent 1.4.1 / VPN 客户端 1.4.1

## 变更

- 节点绑定表格原来的三列 `singbox 模板 / mihomo 模板 / MTProto 模板` 合并为一列「模板」。
- 每个绑定的模板显示为一个标签：
  - `sing-box · <模板名>`（蓝色）
  - `mihomo · <模板名>`（紫色）
  - `MTProto · <模板名>`（橙色）
- 未绑定任何模板显示「未绑定」。
- 多个模板标签自动换行，减少横向空间占用。
- 表格总宽度相应缩小。

- 单模板节点显示一个标签，如 `sing-box · 内置默认`；
- 同时绑定 sing-box + MTProto 的节点显示两个标签；
- 无模板节点显示「未绑定」；
