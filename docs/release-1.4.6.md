# ProxyPilot 1.4.6 发布说明（安装命令包含接入密钥）

日期：2026-11-19
版本：面板 V1.4.6 / Agent 1.4.1 / VPN 客户端 1.4.1

## 变更

- 新建服务器/轮换密钥时生成的 `install_command` 现在包含 `--key ag_...`：
  - 用户复制整条命令到目标服务器执行即可，无需再手工粘贴接入密钥；
  - `install.sh` 仍支持交互输入；命令中的 `--key` 直接使用。
- 安装弹窗提示改为「命令已包含接入密钥，可直接执行（密钥仅本次显示，请妥善保管）」。
- 安全提示：命令包含密钥，可能进入 shell history/截图/聊天记录；请仅在可信环境使用，执行后及时清理 history，密钥泄露时立即轮换。

## 验证

- 单测覆盖：带/不带分发基址的命令均包含 `--key` 与 token；内网地址仍不会进入命令；
- server `go build/vet/test` 全绿；
- 面板 healthz V1.4.6，在线节点正常（新建未接入的“测试”服务器不计入在线）。

## 注意

- 这是对原「命令不含密钥、交互输入」安全设计的便利性调整；如后续要恢复，改回 `buildInstallCommand` 并同步测试即可。
- 密钥仍只在创建/轮换时返回一次。
