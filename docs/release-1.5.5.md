# ProxyPilot 1.5.5 发布说明（节点绑定 CDN 保存后刷新）

日期：2026-11-21
版本：面板 V1.5.5 / Agent 1.4.1 / VPN 客户端 1.4.1

## 修复

节点绑定页保存 CDN 后，界面看起来未更新/未保存：

- 表格新增「CDN」列，显示 `CDN CF +1`、`CDN 已停用` 或 `—`，Tooltip 展示全部 CDN（名称/域名/启用状态）；
- 保存后先关闭/清空表单，再 `await load()` 刷新列表，避免再次编辑拿到旧行数据；
- 编辑前调用 `resetFields()`，切换不同节点时不会残留上一个节点的 CDN；
- 保存结果区分成功/失败：
  - 全部成功：提示成功；若 CDN 有变更，追加「CDN 已保存，重新下发后生效」；
  - 部分失败：提示失败并保留弹窗，刷新列表；
- 后端保存接口未改动；CDN 配置仍需重新下发后应用到节点。
